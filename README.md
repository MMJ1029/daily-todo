# 每日待办 · 任务管理

> 一个**零依赖的单文件网页应用**：每日待办 + 任务模块 + 阶段目标 + 完成度统计。
> 手机竖屏与电脑宽屏自适应，数据保存在浏览器本地，打开即用。

**在线地址**：https://daily-todo-07446.app.workbuddy.host/?sharecode=DTX42IQLSL

## 快速开始

**方式一：直接用在线版**（手机、电脑通用）

打开上面的链接即可，建议加到手机主屏幕。

**方式二：本地打开**

1. 下载本仓库的 `index.html`
2. 双击用浏览器打开，无需安装任何东西
3. 或者起一个本地服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 功能一览

### 每日待办（蓝色）
- 添加待办时可选它在一周中的哪几天显示（默认每天）
- 「今天」页只显示今天安排的待办；今天不安排的收在「非今日安排」里置灰
- 每条前面的 `✓` 一键完成（当天划线置灰，第二天自动恢复待办）
- 每条后面的 `×` 删除（两步确认，防误触）
- 「每日待办」页可随时改任意一条的显示星期

### 任务（橙色）
- 自定义**开始时间 / 结束时间**，时间显示为「10月29日 周四 21:18」，一眼知道星期几
- **开始时间默认 = 当前时间**；结束时间只能从开始时间往后选，选不到更早的日期
- 可添加**图片**（自动压缩，最多 6 张）与**文字说明**
- 点卡片展开看详细说明；点图片可**全屏放大**，右上角 `✕` 关闭
- `✓` 完成后**不消失**，留在「已完成」区
- `✎` 可**二次编辑**（标题 / 时间 / 说明 / 图片都能改）
- `×` 独立删除（两步确认）

### 阶段目标（紫色）
- 主页面顶部显示**精简目标条**：目标名称 + 还有多少天 + 时间进度条，只占一行
- 「目标」页可新增 / 勾选完成 / 删除，显示完整卡片与剩余天数

### 统计（紫色）
- 右上角**醒目徽章**：今天还有几项每日待办没完成，全部完成变绿显示「今日清空」
- 「统计」页：本周完成量与进度
- 当月**完成度日历排盘**：每天一个进度圆环 + 下方百分比，今天用蓝圈标出，可左右切换月份

## 页面结构

| 标签 | 内容 |
| --- | --- |
| **今天** | 精简目标条 + 每日待办 + 未完成任务（按截止时间从早到晚排序） |
| **任务** | 新建/编辑任务表单 + 进行中 / 已完成列表 |
| **每日待办** | 添加表单（输入框 + 星期按钮）+ 全部事项管理 |
| **目标** | 阶段目标区块 |
| **统计** | 本周进度 + 完成度日历排盘 |

## 数据存储

全部数据存在浏览器 `localStorage`，**不上传服务器**：

| 键 | 内容 |
| --- | --- |
| `daily-todos-v1` | 每日待办 |
| `daily-tasks-v1` | 任务 |
| `daily-goals-v1` | 阶段目标 |

- 数据按**设备 + 站点地址**隔离：换设备或换网址是两份数据
- 页面底部提供 **导出备份 / 导入备份**（JSON 文件），可跨设备搬运
- 导入时只有备份里存在对应数组才会覆盖，旧备份不会误清空新数据
- 清除浏览器数据会丢失内容，重要数据请先导出备份

## 技术说明

- 纯原生 HTML / CSS / JavaScript，**无任何第三方依赖、无构建步骤**
- 响应式：手机竖屏单列，≥640px 时居中留白
- 时间选择为自定义「滚轮选择器」（年 / 月 / 日 / 时 / 分五列），避免原生控件在部分手机浏览器上文字不可见的问题
- 颜色约定：蓝 = 每日待办，橙 = 任务，紫 = 阶段目标与统计
